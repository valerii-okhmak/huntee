# Test Format and Security Systems

Huntee ensures fairness and transparency in testing results through user behavior monitoring and control technologies.

## 1. Question Types

- **Multiple Choice** — selection of one or more correct answers.
- **Open-ended Answers** — text input with reasoning or code explanation.
- **Matching** — linking related items or concepts.
- **Practical Tasks (Coding)** — programming tasks performed in an online code editor.

## 2. Time Limits

- Each test has a fixed time limit defined by the administrator. Once the time expires, access to the test is terminated.

## 3. Anti-cheating Mechanisms

- **Eye Tracking**: The system can monitor eye movement via webcam and detect if the user looks away from the screen.
- **Screen Recording**: The test session is recorded to track user activity.
- **Tab Switching Control**: Detects attempts to switch to other applications or browser tabs.
- **Automatic Termination**: In case of detected violations, the test may be automatically ended with an appropriate flag.

## 4. Number of Questions

- Varies depending on the specific test.

## 5. Evaluation

- Test results are calculated automatically immediately after completion.
- The final score depends on the number of correct answers and the weight of each question.

## 6. Results

- Students receive their results and analytics immediately after finishing the test.
- Companies can review all candidate answers, analyze performance, and generate rankings.

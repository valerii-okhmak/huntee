# Career Test Logic & Question Flow

## 1. General Description

The **Career Test** is an interactive assessment designed to determine the user's professional interests. The logic of the test is structured so that the questions change dynamically depending on the user's previous answers. This creates a personalized path through the test and yields much more accurate career recommendations. 

The core principle of the system is an adaptive **Question Flow**, where every answer given by the user dictates the subsequent question or group of questions.

## 2. Core Test Logic

1. The user starts the test.
2. The system displays the first, general-level question.
3. The user selects one of the provided answers.
4. Based on that selection, the system determines the next appropriate question.
5. This process repeats until the test is completed.
6. Upon completion, the system analyzes the user's answers and generates a tailored career recommendation.

## 3. Decision Tree

The system utilizes a decision tree structure, where:
- **Node:** Each question.
- **Transition:** Each answer.
- **Path:** Each transition leads to the next specific question.

**Logic Example:**

* **Question 1:** *What type of activities do you enjoy most?*
  * Options: Creative, Analytical, Social, Technical

* **If the user selects "Creative":**
  * **Next question:** *What do you enjoy more?*
  * Options: Visual design, Writing / storytelling, Marketing / branding, Content creation

* **If the user selects "Analytical":**
  * **Next question:** *What interests you the most?*
  * Options: Working with numbers, Research and analysis, Problem solving, Data interpretation

## 4. Adaptive Question Flow

Questions adapt and change based on the user's input history.

**Example Flow:**
- **IF** user selects "Creative"
  - **THEN** show questions related to: Design, Marketing, Content creation
- **IF** user selects "Technical"
  - **THEN** show questions related to: Programming, Engineering, Cybersecurity, IT Support

This approach ensures the test feels personalized and significantly reduces the number of irrelevant questions the user has to answer.

## 5. Logic Implementation Options

### Option 1 — Decision Tree (Basic Implementation)
A static question tree: `Question → Answer → Next Question`
- **Pros:** Simple to implement, clear logic, easy to test.
- **Cons:** Less flexible when scaling up to a large number of questions.

### Option 2 — Rule-Based Logic
The system operates based on predefined conditional rules. 
- *Example:* `IF answer = Creative THEN next category = Design / Marketing`
- **Pros:** Highly flexible, easy to update or change rules.
- **Cons:** Can become complex and difficult to maintain as the number of conditions grows.

### Option 3 — Score-Based System
Each answer adds points (weight) to a specific category. 
- *Example:* `Creative → +2`, `Analytical → +1`, `Technical → +0`
- At the end of the test, the system identifies the category with the highest score and suggests corresponding career paths.
- **Pros:** High accuracy in recommendations, enables deeper analysis of results.

### ⭐️ Recommended Solution — Hybrid Approach
We recommend using a combined approach: **Decision Tree + Score System**
- Questions adapt to previous answers (Decision Tree).
- Points are accumulated in the background simultaneously (Score System).
- The final result is calculated based on the totality of the answers and their respective weights.

## 6. Data Stored by the System

To function properly, the system must log the following data points:
- `user_id`
- `question_id`
- `selected_answer`
- `category`
- `score`
- `timestamp`

**This allows the platform to:**
- Analyze test results;
- Save and restore user progress;
- Build backend analytics and insights.

## 7. Acceptance Criteria (AC)

- [ ] The Decision Tree logic is implemented.
- [ ] Every answer successfully routes the user to the correct subsequent question.
- [ ] Questions adapt dynamically based on the user's input.
- [ ] The system successfully saves the user's answers to the database.
- [ ] The system accurately calculates scores for each distinct category.
- [ ] A final career recommendation is generated and displayed at the end of the test.

## 8. Expected Result

Upon completing the test, the user will receive a highly personalized result screen, such as:

> **Based on your answers, your strongest career paths are:**
> - UX/UI Designer
> - Digital Marketer
> - Data Analyst
> - Software Engineer

This result is generated by analyzing the specific path the user took and identifying the categories that accumulated the highest scores.

# Huntee App

Веб-додаток для онлайн тестування кандидатів під час попереднього відбору на вакансії. Призначений для IT-компаній, які шукають ефективний інструмент для швидкого та точного відбору кандидатів.

## Опис

Huntee App — це платформа, що дозволяє IT-компаніям проводити онлайн тестування кандидатів для попереднього відбору на вакансії. Після успішного проходження тестів кандидати отримують запрошення на роботу. Додаток має простий інтерфейс для адміністраторів і кандидатів, що забезпечує легкий процес тестування та оцінювання.

### Можливості для компаній:
- **Створення тестів**: Адміністратори можуть створювати та налаштовувати тести для кандидатів, включаючи різні типи питань (множинний вибір, відкриті питання тощо).
- **Моніторинг результатів**: Адміністратори можуть переглядати результати тестів у реальному часі, аналізувати відповіді кандидатів і робити висновки.
- **Аналіз ефективності кандидатів**: За допомогою автоматичної оцінки відповідей система дозволяє швидко визначити найкращих кандидатів.

### Можливості для студентів:
- **Проходження тестів**: Студенти можуть проходити тести, що складаються з різних типів завдань, які оцінюють їхні знання та навички в різних сферах.
- **Відслідковування результатів**: Після проходження тесту студенти можуть переглядати свої результати та оцінки, що дає їм можливість зрозуміти, в яких сферах вони сильні, а де потрібно покращувати.
- **Запрошення на співбесіду**: Студенти, які показали високі результати в тестах, отримують можливість пройти співбесіду в компаніях, що використовують платформу.

## Формат тестування

### 1. Типи запитань:
- **Множинний вибір:** кандидати обирають одну або кілька правильних відповідей з декількох варіантів.
- **Відкриті питання:** кандидати повинні надати текстову відповідь на задане питання.
- **Запитання на відповідність:** кандидати повинні співвіднести елементи з двох списків.
- **Практичні завдання:** кандидати можуть бути запитані виконати певну задачу на програмування.

### 2. Часові обмеження:
- Кожен тест має обмеження часу, яке встановлюється адміністратором тесту.

### Системи запобігання шахрайству:
**1. Відслідковування рухів очей:** Під час проходження тесту система використовує спеціальні алгоритми для аналізу рухів очей кандидата, щоб виявити можливі спроби підглядання за допомогою інших екранів або перегляду зовнішніх джерел. У разі підозр на порушення, тест може бути автоматично зупинено.

**2. Запис екрану:** Для додаткової безпеки, тестування може супроводжуватися записом екрана, що дозволяє адміністратору переглядати активність кандидата під час проходження тесту. Це допомагає забезпечити, щоб кандидат не переключався на інші програми чи веб-сторінки під час тестування.


### 3. Кількість питань:
- Кількість питань може варіюватися в залежності від рівня тестування, напрямку.

### 4. Оцінювання:
- Тестування оцінюється автоматично: кожна правильна відповідь дає певну кількість балів.
- Загальна кількість балів залежить від кількості правильних відповідей і складності питань.
- Кандидати отримують результат одразу після завершення тесту, що дозволяє їм побачити свої сильні та слабкі сторони.

### 4. Підсумки:
- Після завершення тесту кандидати можуть переглянути свої відповіді та отриману оцінку.
- Компанії, які проводять тест, мають змогу переглянути результати та обрати найкращих кандидатів.

## Технології

### Бекенд
- **Java** — сервер для обробки запитів та API.
- **Spring Boot** — фреймворк для створення веб-додатків на Java, який полегшує налаштування і розгортання.
- **Swagger** — інструмент для автоматичної генерації документації API, що забезпечує легкість інтеграції та тестування API.
- **OAuth2** — протокол аутентифікації та авторизації, що дозволяє безпечно надавати доступ до ресурсів користувача через сторонні сервіси.

### Фронтенд
- **React** — бібліотека для створення динамічних інтерфейсів користувача, що дозволяє будувати швидкі та масштабовані веб-додатки.


## Встановлення
### Клонуйте репозиторій:
```bash
git clone https://github.com/DONAT1N/huntee.git
```
### Встановіть залежності:
Перейдіть в каталог проекту та встановіть необхідні пакети.
```bash
cd huntee
cd frontend
npm install
```

## Запуск
Запустіть програму:

```bash
npm start
```
Додаток буде доступний за адресою http://localhost:3000.

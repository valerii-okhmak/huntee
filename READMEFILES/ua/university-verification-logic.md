# University Verification Logic & Flow (SSO Only)


## 1. Загальний опис

**University Verification** — це автоматизований механізм підтвердження академічного статусу користувача (студента) за допомогою технології Single Sign-On (SSO) через корпоративні акаунти закладів вищої освіти (Google Workspace for Education або Microsoft Entra ID).
Система автентифікує користувача через провайдера, перевіряє домен отриманої електронної пошти на відповідність базі дозволених освітніх доменів (Whitelist) і автоматично присвоює профілю бейдж `Verified Student`.

## 2. Основна логіка роботи (SSO Verification Flow)

1. **Ініціація верифікації:** Користувач переходить у налаштування профілю (розділ "Верифікація") і натискає кнопку "Підтвердити через акаунт університету" (Sign in with Google / Microsoft).
2. **Автентифікація (OAuth 2.0):** Користувача перенаправляє на сторінку входу провайдера (Google або Microsoft), де він вводить свої студентські облікові дані (наприклад, `student.name@lpnu.ua`).
3. **Отримання даних:** Після успішного входу провайдер повертає бекенду Huntee токен та базовий профіль користувача (email).
4. **Перевірка домену (Domain Validation):** Система витягує домен з отриманого email-у (частину після `@`) та перевіряє його за внутрішньою базою (Whitelist) підтримуваних університетів.
5. **Оновлення статусу:** Якщо домен валідний, статус користувача миттєво змінюється на `Verified`, а до профілю прив'язується відповідний бейдж університету.

## 3. Реалізація логіки

Платформа використовує **виключно OAuth / SSO Integration** (офіційні API Google та Microsoft) для верифікації. Підтвердження через відправку листів із посиланнями (Email Token) або ручна перевірка документів **не використовуються**.

- **Переваги такого підходу:** - Найвищий рівень безпеки (неможливо підробити лист, відсутній ризик витоку токенів).
  - Миттєве підтвердження без необхідності переходити в поштову скриньку.
  - Найкращий User Experience (UX).
  - Відсутність навантаження на власні поштові сервіси.

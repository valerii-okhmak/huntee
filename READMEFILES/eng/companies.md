# Features for Companies

Huntee provides IT companies with a powerful toolkit for effective candidate pre-screening.

## Key Features:

- **Test Creation**: Administrators can create tests with various question types (multiple choice, open-ended, coding tasks, etc.), set time limits, and define passing criteria. *See more in [Test Format](READMEFILES/end/test-format.md#1-question-types)*

- **Role-based Personalization**: Ability to create test templates tailored to specific job positions (e.g., "Junior Java Developer").

- **Process Monitoring**: View the current status of each candidate’s test (started, completed, time remaining).

- **Result Evaluation**: Automatic scoring upon test completion, with weighting based on task difficulty.

- **Performance Analysis**: Candidate ranking, group-based analytics, and test history tracking.

- **Security**: Integrity monitoring tools (e.g., eye tracking). *See more in [Anti-cheating Mechanisms](READMEFILES/eng/test-format.md#3-anti-cheating-mechanisms)*

- **Result Export**: Export test reports in CSV/Excel formats.

## Usage:

1. **Create an Account**  
   Register a corporate account on the Huntee platform.

2. **Build Tests**  
   Create assessments by selecting question types relevant to the job opening (multiple choice, open-ended, coding tasks).

3. **Assign Tests to Candidates**  
   Assign tests to candidates directly through the platform interface.

4. **Analyze Results**  
   Monitor test performance in real time and use analytics to compare candidates.

5. **Send Interview Invitations**  
   Invite top-performing candidates for interviews based on their test results.

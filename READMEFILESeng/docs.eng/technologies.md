# Technologies

## Backend
- **Java** — the server-side language used to handle requests and APIs.
- **Spring Boot** — a framework for building Java-based web applications that simplifies setup and deployment.
- **Swagger** — a tool for automatically generating API documentation, making integration and testing easier.
- **OAuth2** — an authentication and authorization protocol that enables secure access to user resources through third-party services.

## Frontend
- **React** — a library for building dynamic user interfaces, allowing for fast and scalable web applications.

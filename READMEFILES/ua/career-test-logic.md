# Career Test Logic & Question Flow

## 1. Загальний опис

**Career Test** — це інтерактивний тест для визначення професійних інтересів користувача. Логіка тесту побудована таким чином, що питання змінюються залежно від попередніх відповідей користувача. Це дозволяє створити персоналізований шлях проходження тесту та отримати більш точні рекомендації щодо кар'єри.

Основний принцип роботи системи — адаптивний **Question Flow**, де кожна відповідь користувача визначає наступне питання або групу питань.

## 2. Основна логіка роботи тесту

1. Користувач починає тест.
2. Система показує перше питання загального характеру.
3. Користувач обирає одну з відповідей.
4. На основі вибору система визначає наступне питання.
5. Процес повторюється до завершення тесту.
6. Наприкінці система аналізує відповіді користувача та формує рекомендацію щодо кар'єри.

## 3. Decision Tree (Дерево рішень)

Система використовує структуру дерева рішень, де:
- **Вузол:** кожне питання.
- **Перехід:** кожна відповідь.
- **Шлях:** кожен перехід веде до наступного питання.

**Приклад логіки:**

* **Питання 1:** *What type of activities do you enjoy most?*
  * Варіанти відповідей: Creative, Analytical, Social, Technical

* **Якщо користувач обирає "Creative":**
  * **Наступне питання:** *What do you enjoy more?*
  * Варіанти: Visual design, Writing / storytelling, Marketing / branding, Content creation

* **Якщо користувач обирає "Analytical":**
  * **Наступне питання:** *What interests you the most?*
  * Варіанти: Working with numbers, Research and analysis, Problem solving, Data interpretation

## 4. Логіка адаптації питань (Adaptive Question Flow)

Питання змінюються залежно від попередніх відповідей користувача.

**Приклад:**
- **IF** user selects "Creative"
  - **THEN** show questions related to: Design, Marketing, Content creation
- **IF** user selects "Technical"
  - **THEN** show questions related to: Programming, Engineering, Cybersecurity, IT Support

Це забезпечує персоналізацію тесту та скорочує кількість нерелевантних питань.

## 5. Варіанти реалізації логіки

### Option 1 — Decision Tree (Базова реалізація)
Статичне дерево питань: `Question → Answer → Next Question`
- **Переваги:** проста реалізація, зрозуміла логіка, легко тестувати.
- **Недоліки:** менш гнучка при великій кількості питань.

### Option 2 — Rule-Based Logic
Система працює на основі правил.
- *Приклад:* `IF answer = Creative THEN next category = Design / Marketing`
- **Переваги:** гнучкість, легко змінювати правила.
- **Недоліки:** складніше підтримувати при великій кількості умов.

### Option 3 — Score-Based System
Кожна відповідь додає бали до певної категорії.
- *Наприклад:* `Creative → +2`, `Analytical → +1`, `Technical → +0`.
- Наприкінці тесту система визначає категорію з найбільшою кількістю балів та пропонує відповідні кар'єрні напрями.
- **Переваги:** висока точність рекомендацій, можливість аналізу результатів.

### ⭐️ Recommended Solution — Hybrid Approach
Рекомендується використовувати комбінований підхід: **Decision Tree + Score System**
- Питання адаптуються до відповідей (Дерево рішень).
- Паралельно накопичуються бали (Система балів).
- Фінальний результат визначається на основі сукупності відповідей.

## 6. Дані, які зберігає система

Система повинна зберігати:
- `user_id`
- `question_id`
- `selected_answer`
- `category`
- `score`
- `timestamp`

**Це дозволяє:**
- аналізувати результати;
- відновлювати прогрес;
- будувати аналітику.

## 7. Acceptance Criteria (AC)

- [ ] Реалізовано дерево рішень (Decision Tree).
- [ ] Кожна відповідь веде до наступного відповідного питання.
- [ ] Питання адаптуються залежно від відповідей користувача.
- [ ] Система зберігає відповіді користувача в базі даних.
- [ ] Система розраховує бали для кожної категорії.
- [ ] Наприкінці тесту формується рекомендація щодо кар'єри.

## 8. Очікуваний результат

Після завершення тесту користувач отримує персоналізований результат, наприклад:

> **Based on your answers, your strongest career paths are:**
> - UX/UI Designer
> - Digital Marketer
> - Data Analyst
> - Software Engineer

Результат формується на основі аналізу відповідей та категорій з найвищими балами.

# Huntee App

- [English version](READMEFILES/end/README.md)

**Huntee** — веб-платформа для онлайн тестування кандидатів з вбудованими механізмами контролю доброчесності. Платформа забезпечує IT-компаніям ефективний інструмент для первинного відбору спеціалістів, а студентам — можливість продемонструвати свої навички та отримати запрошення на співбесіду.

## Опис

Huntee App — це платформа, що дозволяє IT-компаніям проводити онлайн тестування кандидатів для попереднього відбору на вакансії. Після успішного проходження тестів кандидати отримують запрошення на роботу. Додаток має простий інтерфейс для адміністраторів і кандидатів, що забезпечує легкий процес тестування та оцінювання.

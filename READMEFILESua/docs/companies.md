# Можливості для компаній

Huntee надає IT-компаніям потужний інструментарій для ефективного попереднього відбору кандидатів.

## Основні функції:

- **Створення тестів**: Адміністратор може створити тести з різними типами питань (множинний вибір, відкриті питання, кодинг-завдання, тощо), визначити тривалість тесту та критерії проходження.

- **Персоналізація під вакансії**: Можливість створювати шаблони тестів під конкретні ролі (наприклад, "Junior Java Developer").

- **Моніторинг процесу**: Перегляд поточного статусу проходження тесту кандидатами (почав, завершив, залишилось часу).

- **Оцінка результатів**: Автоматичне виставлення балів після проходження тесту, з урахуванням складності завдань.

- **Аналіз ефективності**: Побудова рейтингів кандидатів, аналітика за групами, збереження історії тестування.

- **Безпека**: Використання механізмів контролю доброчесності кандидатів (запис екрана, контроль погляду).

- **Експорт результатів**: Завантаження звітів про проходження тестів у форматах CSV/Excel.

## Використання:

1. **Створення облікового запису**  
   Зареєструйте корпоративний обліковий запис на платформі Huntee.

2. **Формування тестів**  
   Створюйте тестові завдання, обираючи типи запитань відповідно до вакансії (множинний вибір, відкриті відповіді, кодинг-завдання).

3. **Призначення тестів кандидатам**  
   Призначайте тести кандидатам безпосередньо через інтерфейс платформи.

4. **Аналіз результатів**  
   Переглядайте результати тестування в реальному часі, використовуйте аналітику для порівняння кандидатів.

5. **Запрошення на співбесіду**  
   На основі отриманих результатів надсилайте запрошення на співбесіду відібраним кандидатам.
